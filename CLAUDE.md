# Notes for Claude

## Facts: always verify online
- Never state facts from memory alone (news, games, people, dates, rankings, prices, etc.).
- Check every factual claim with a web search before answering, and cite sources.
- Prefer official / primary sources (company filings and press releases, official
  sites, official APIs such as pointercrate.com for the Geometry Dash Demonlist) over
  wikis, fan sites, quizzes and reposts. When sources disagree, the official one wins.
- If something can't be verified, say so plainly instead of guessing.
