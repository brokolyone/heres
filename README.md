# Heres: снайперка и скейт (мод для Minecraft 1.21.1)

Мод на **Fabric** для **Minecraft Java 1.21.1** (и 1.21). В нём две вещи с настоящими 3D-моделями:

- **Снайперская винтовка M98B.** Модель взята из `art/precision_rifle.blend` и запечена в игровую текстуру:
  оптический прицел, дульный тормоз, сошки, планки.
- **Скейтборд.** Смоделирован в Blender с нуля: дека с загнутыми носом и хвостом и прогибом,
  чёрная шкурка, графика на днище, фанера на торце, подвески, колёса.

Цель — встать на скейт, сделать олли и снять Эндер-дракона в прыжке.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/installer/) для 1.21.1.
2. Скачай [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.1.
3. Положи `heres-sniper-skate-1.0.0.jar` и Fabric API в папку `.minecraft/mods`.
4. Запусти игру через профиль Fabric.

## Как получить

- В творческом режиме: снайперка во вкладке «Бой», скейт во вкладке «Инструменты».
- Командой: `/function heres:give` (или `/give @s heres:sniper`, `/give @s heres:skateboard`).
- Крафтом:
  - **снайперка**: подзорная труба сверху, ряд «железный блок + 2 железных слитка», доска тёмного дуба снизу слева;
  - **скейт**: 3 любые доски сверху, 2 слизи по краям снизу.
- Дракон для тренировки: `/function heres:dragon`.

## Управление

**Снайперка**

| Кнопка | Действие |
|---|---|
| ЛКМ | выстрел (дальность 256 блоков, мгновенная пуля с трассером) |
| зажать ПКМ | прицел ×10 с сеткой милдот, мышь становится медленнее |

- Затвор: 1,5 с между выстрелами.
- Урон 40. Попадание в голову даёт ×1,5.
- **Дракону хватает 5 попаданий в тело, а в голову — 3.**
- После выстрела ствол подкидывает отдачей.

**Скейт**

| Кнопка | Действие |
|---|---|
| ПКМ по земле | поставить скейт и встать на него (с Shift — только поставить) |
| W / S | толкаться / тормозить |
| A / D | поворачивать |
| Пробел | олли с кикфлипом, запрыгивает на блок |
| Shift | слезть |
| удар по скейту | подобрать |

На скейте нет урона от падения. Стрелять с доски можно прямо на ходу.

## Сборка

```
gradle build          # → build/libs/heres-sniper-skate-1.0.0.jar
gradle runClient      # игра с модом
gradle runAutotest    # сценарий-проверка со скриншотами в run/screenshots (нужен мир run/saves/test)
```

## Откуда модели, текстуры и звуки

Всё воспроизводимо скриптами из `tools/`:

| Скрипт | Что делает |
|---|---|
| `tools/blender/bake_export.py` | объединяет детали модели, упрощает сетку, делает UV-развёртку, запекает цвет со светом и AO в одну текстуру, экспортирует треугольники с плавными нормалями (`.mesh`) |
| `tools/blender/build_skateboard.py` | моделирует скейт |
| `tools/textures/make_skate_textures.py` | рисует шкурку, графику на деке и фанеру |
| `tools/textures/make_scope.py` | рисует сетку прицела |
| `tools/audio/make_sounds.py` | синтезирует выстрел, затвор, олли, приземление и шум колёс |

Пример для винтовки (Blender 4.5):

```
blender -b art/precision_rifle.blend --python tools/blender/bake_export.py -- \
    src/main/resources/assets/heres/meshes/sniper.mesh \
    src/main/resources/assets/heres/textures/item/sniper.png 2048 12000
```

## Сцена «Стеклянный коридор»

Отдельная Blender-сцена по картинке `art/corridor/reference.png`: коридор со сплошным
витражом, солнечная полоса на глянцевом полу, рисовые поля и лес за окном.

```
blender -b --factory-startup --python tools/blender/build_corridor.py -- art/corridor \
    --render art/corridor/render.png --scale 2 --samples 160
```

Скрипт собирает `art/corridor/corridor.blend` и рендерит кадр. Камера восстановлена по
точкам схода референса. Коридор — переход на высоте 3.5 м над рисовыми полями. Рис
сгенерирован процедурно: ~290 тыс. кустиков в трёх поясах по дальности. Лес собран из
~3500 крон поверх сплошного массива листвы. Сорняки у стекла — скан папоротника с
Poly Haven (лицензия CC0) из `art/corridor/assets`. Цвета подогнаны по зонам кадра
скриптом `tools/blender/fit_corridor.py`.

Обычные модели Minecraft собираются только из кубиков. Поэтому мод рисует настоящую
треугольную сетку через Fabric Renderer API, с нормалями на каждой вершине,
чтобы ствол, прицел и колёса выглядели круглыми.
