# ArtGraf

Растровый графический редактор для Windows на C++. Слои, кисти, выделения, фильтры и коррекция,
история действий. Собирается в один `ArtGraf.exe` без DLL рядом.

Весь код написан с нуля. Иконки нарисованы примитивами прямо в коде, сторонних картинок
и шрифтов в программе нет.

## Возможности

**Инструменты** (буква — горячая клавиша)

| | | | |
|---|---|---|---|
| `V` Перемещение | `M` Прямоугольная область | `O` Овальная область | `L` Лассо |
| `W` Волшебная палочка | `C` Кадрирование | `I` Пипетка | `B` Кисть |
| `N` Карандаш | `E` Ластик | `S` Штамп (Alt+клик — источник) | `G` Градиент (линейный/радиальный) |
| `K` Заливка | `T` Текст (любой TTF-шрифт) | `U` Фигуры (прямоугольник, эллипс, линия) | `H` Рука, `Z` Масштаб |

**Слои:** 15 режимов наложения (умножение, экран, перекрытие, мягкий/жёсткий свет, разница…),
непрозрачность, видимость, перетаскивание для смены порядка, переименование двойным кликом,
дублирование, объединение, сведение, «скопировать на новый слой» (Ctrl+J).

**Выделение:** новое / добавить (Shift) / вычесть (Alt) / пересечь (Shift+Alt), растушевка,
инверсия. Кисти, фильтры, заливка и перемещение работают только внутри выделения.

**Коррекция:** яркость/контраст, уровни, цветовой тон/насыщенность, цветовой баланс,
автоконтраст, обесцвечивание, инверсия, сепия, постеризация, порог. Все — с живым предпросмотром.

**Фильтры:** размытие по Гауссу, размытие в движении, контурная резкость, шум, пикселизация,
тиснение, выделение краёв, масляная краска, виньетка.

**Изображение:** размер изображения, размер холста с привязкой, поворот 90°/180°, отражение,
кадрирование по выделению, обрезка прозрачных краёв, трансформирование слоя (масштаб, поворот, сдвиг).

**Файлы:** открытие PNG, JPEG, BMP, TGA, GIF, PSD (сведённое изображение), HDR. Экспорт в PNG,
JPEG, BMP, TGA. Собственный формат проекта `.agf` сохраняет слои: это zip с `project.json`
и PNG каждого слоя. Можно перетащить картинку в окно. Копирование и вставка работают через буфер
обмена Windows, поэтому скриншоты вставляются по Ctrl+V.

**Прочее:** история с откатом на любой шаг, навигатор, пиксельная сетка, панели можно
перетаскивать и пристыковывать куда угодно (расположение запоминается).

Полный список горячих клавиш: **Справка → Горячие клавиши** (F1).

## Из чего сделано

| Библиотека | Для чего |
|---|---|
| [SDL2](https://libsdl.org) | окно, ввод, перетаскивание файлов |
| [Dear ImGui](https://github.com/ocornut/imgui) (docking) | интерфейс и пристыковываемые панели |
| OpenGL 3 | вывод холста на экран |
| [stb_image / stb_image_write](https://github.com/nothings/stb) | чтение и запись картинок |
| [stb_image_resize2](https://github.com/nothings/stb) | изменение размера изображения |
| [stb_truetype](https://github.com/nothings/stb) | инструмент «Текст» |
| [nativefiledialog-extended](https://github.com/btzy/nativefiledialog-extended) | системные окна «Открыть» / «Сохранить» |
| [nlohmann/json](https://github.com/nlohmann/json) | метаданные проекта `.agf` |
| [miniz](https://github.com/richgel999/miniz) | zip-контейнер `.agf` |

Зависимости скачиваются автоматически при первой сборке (CMake FetchContent) и закреплены
на конкретных версиях.

## Сборка

Нужны CMake 3.20+ и компилятор с C++17.

### Windows `.exe` из Linux (MinGW-w64), проверенный способ

```sh
sudo apt install cmake ninja-build mingw-w64
cmake -S artgraf -B build-win -G Ninja -DCMAKE_TOOLCHAIN_FILE=$PWD/artgraf/cmake/mingw-w64-x86_64.cmake
cmake --build build-win
# готово: build-win/ArtGraf.exe
```

Готовый `.exe` также собирается в GitHub Actions (workflow **ArtGraf**) при каждом изменении
в `artgraf/`: его можно скачать из артефактов запуска.

### Linux (для разработки)

```sh
sudo apt install cmake ninja-build libgl-dev libx11-dev libxext-dev libxrandr-dev libxcursor-dev libxi-dev
cmake -S artgraf -B build -G Ninja
cmake --build build
./build/ArtGraf
```

На Linux вместо системных диалогов используется встроенный файловый браузер.

### Тесты ядра

```sh
cmake -S artgraf -B build-tests -DARTGRAF_BUILD_APP=OFF
cmake --build build-tests && ctest --test-dir build-tests
```

## Устройство кода

```
src/core/   ядро без интерфейса (тестируется отдельно)
  image      RGBA-изображение, поворот, отражение, масштаб
  blend      режимы наложения
  document   слои, выделение, история отмен, сведение
  raster     мазки кисти, фигуры, многоугольники, заливка по цвету
  filters    коррекция и фильтры
  text       рендер текста (stb_truetype)
  io         картинки, проект .agf, пути UTF-8 на Windows
src/app/    программа: окно, панели, инструменты
  main.cpp          SDL + OpenGL + ImGui, главный цикл
  editor.cpp        документ, экранная текстура, команды меню
  editor_tools.cpp  инструменты и живой предпросмотр
  editor_ui.cpp     меню, панели, диалоги, горячие клавиши
  file_dialog.cpp   системные диалоги или встроенный браузер
  clipboard.cpp     буфер обмена Windows (PNG и CF_DIB)
  icons.cpp         иконки инструментов
```

Мазок кисти сначала рисуется в отдельную маску покрытия и только при отпускании мыши переносится
в слой. Поэтому мазок с непрозрачностью 50% не темнеет на пересечениях, а отмена убирает его целиком.
Сведение слоёв для экрана пересчитывает только изменившийся прямоугольник и раскладывается по всем
ядрам процессора.
