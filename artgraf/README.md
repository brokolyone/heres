# ArtGraf

Растровый графический редактор для Windows на C++. Слои, кисти, выделения, фильтры и коррекция,
история действий. Собирается в один `ArtGraf.exe` без DLL рядом.

Весь код написан с нуля. Иконки инструментов рисуются примитивами прямо в коде; логотип
и заставка генерируются скриптом `res/make_art.py` и встраиваются в `.exe` при сборке.

## Возможности

**Интерфейс:** тёмная тема со скруглёнными панелями, заставка при запуске, домашний экран
с быстрым стартом и недавними файлами, вкладки документов (Ctrl+Tab), панели можно перетаскивать
и пристыковывать (расположение запоминается), окно «Новый документ» с шаблонами по категориям
(фото, печать, иллюстрации, веб, мобильные, видео), единицами (px, см, мм, дюймы) и разрешением.

**25 инструментов** в группах, как в больших редакторах: клавиша выбирает группу, Shift+клавиша
переключает инструмент внутри неё, правый клик по кнопке показывает всю группу.

| Клавиша | Инструменты |
|---|---|
| `V` | Перемещение |
| `M` | Прямоугольная и овальная область |
| `L` | Лассо, прямолинейное лассо |
| `W` | Волшебная палочка |
| `C` | Кадрирование |
| `I` | Пипетка |
| `J` | Точечная восстанавливающая кисть, штамп |
| `B` | Кисть, карандаш |
| `E` | Ластик |
| `G` | Градиент, заливка (`K`) |
| `R` | Размытие, резкость, палец |
| `O` | Осветлитель, затемнитель, губка |
| `T` | Текст (любой TTF/OTF-шрифт) |
| `U` | Фигуры: прямоугольник, скруглённый, эллипс, линия, стрелка, многоугольник, звезда, сердце |
| `H`, `Z` | Рука, масштаб |

**Кисти:** 19 наборов с превью мазка (жёсткая, мягкая, аэрограф, каллиграфия, перо-маркер,
квадратная, пиксель, мел, уголь, сухая кисть, акварель, распылитель, кляксы, звёзды, листья,
трава, сердечки, облака). Настройки отпечатка и динамики (F5): интервалы, угол, форма,
колебание размера, угла и нажима, рассеивание, накопление, поворот по штриху. Стабилизатор
мазка. Свои кисти из изображения или из выделения.

**Градиенты:** 5 типов (линейный, радиальный, угловой, зеркальный, ромбовидный), 16 наборов,
редактор контрольных точек с прозрачностью, инверсия, дизеринг.

**Стили слоя (эффекты):** тень, внешнее и внутреннее свечение, тиснение, обводка, наложение
цвета и градиента, быстрые стили. Стили не меняют пиксели и сохраняются в проекте.

**Слои:** 15 режимов наложения, непрозрачность, видимость, перетаскивание, переименование,
дублирование, объединение, сведение, «скопировать на новый слой» (Ctrl+J), растрирование стиля.

**Выделение:** новое / добавить / вычесть / пересечь, растушевка, инверсия, обводка выделения.

**Коррекция:** яркость/контраст, уровни, кривые (Ctrl+M), экспозиция, сочность, тон/насыщенность,
цветовой баланс, чёрно-белое, фотофильтр, микширование каналов, карта градиента, автоконтраст,
обесцвечивание, инверсия, сепия, соляризация, постеризация, порог. Всё с живым предпросмотром.

**Фильтры:** размытие по Гауссу, в движении, радиальное, вращением, тилт-шифт; скручивание,
сферизация, волна, рябь, полярные координаты; контурная резкость, шум, медиана; пикселизация,
кристаллизация, цветные полутона; облака, блик, виньетка; тиснение, края, масляная краска,
набросок карандашом, глитч, хроматическая аберрация.

**Файлы и импорт:** PNG, JPEG, BMP, TGA, GIF, PSD (сведённое изображение), HDR; экспорт в PNG,
JPEG, BMP, TGA; проект `.agf` (zip: `project.json` + PNG слоёв). Импорт картинки как слоя,
нескольких картинок слоями, нового документа из буфера обмена. Буфер обмена Windows, недавние файлы,
перетаскивание файлов в окно.

Полный список горячих клавиш: **Справка → Горячие клавиши** (F1).

## Из чего сделано

| Библиотека | Для чего |
|---|---|
| [SDL2](https://libsdl.org) | окно, ввод, перетаскивание файлов |
| [Dear ImGui](https://github.com/ocornut/imgui) (docking) | интерфейс и пристыковываемые панели |
| OpenGL 3 | вывод холста на экран |
| [stb_image / stb_image_write](https://github.com/nothings/stb) | чтение и запись картинок |
| [stb_image_resize2](https://github.com/nothings/stb) | изменение размера изображения |
| [stb_truetype](https://github.com/nothings/stb) | инструмент «Текст» |
| [nativefiledialog-extended](https://github.com/btzy/nativefiledialog-extended) | системные окна «Открыть» / «Сохранить» |
| [nlohmann/json](https://github.com/nlohmann/json) | метаданные проекта `.agf` |
| [miniz](https://github.com/richgel999/miniz) | zip-контейнер `.agf` |

Зависимости скачиваются автоматически при первой сборке (CMake FetchContent) и закреплены
на конкретных версиях.

## Сборка

Нужны CMake 3.20+ и компилятор с C++17.

### Windows `.exe` из Linux (MinGW-w64), проверенный способ

```sh
sudo apt install cmake ninja-build mingw-w64
cmake -S artgraf -B build-win -G Ninja -DCMAKE_TOOLCHAIN_FILE=$PWD/artgraf/cmake/mingw-w64-x86_64.cmake
cmake --build build-win
# готово: build-win/ArtGraf.exe
```

Готовые `.exe` и `.apk` также собираются в GitHub Actions (workflow **ArtGraf**) при каждом
изменении в `artgraf/`: их можно скачать из артефактов запуска.

### Android `.apk`

Тот же код собирается в приложение для Android 7.0+ (arm64, armv7, x86_64). На телефоне:
один палец рисует, двумя пальцами — масштаб и сдвиг; «Открыть» вызывает системный выбор файла
(галерея, «Файлы», Диск), экспорт картинок сохраняется в «Галерею» (Pictures/ArtGraf), проекты —
в папку приложения. Интерфейс тот же, что на компьютере, поэтому удобнее всего на планшете.

```sh
# нужны JDK 17+, Gradle 8.9+, Android SDK с NDK 26 и CMake 3.22
cd artgraf/android
echo "sdk.dir=$ANDROID_HOME" > local.properties
gradle assembleRelease
# готово: app/build/outputs/apk/release/app-release.apk (подписан отладочным ключом)
```

### Linux (для разработки)

```sh
sudo apt install cmake ninja-build libgl-dev libx11-dev libxext-dev libxrandr-dev libxcursor-dev libxi-dev
cmake -S artgraf -B build -G Ninja
cmake --build build
./build/ArtGraf
```

На Linux вместо системных диалогов используется встроенный файловый браузер.

### Тесты ядра

```sh
cmake -S artgraf -B build-tests -DARTGRAF_BUILD_APP=OFF
cmake --build build-tests && ctest --test-dir build-tests
```

## Устройство кода

```
src/core/   ядро без интерфейса (тестируется отдельно)
  image      RGBA-изображение, поворот, отражение, масштаб
  blend      режимы наложения
  document   слои, выделение, история отмен, сведение
  raster     мазки кисти, фигуры, многоугольники, заливка по цвету
  filters    коррекция и фильтры
  text       рендер текста (stb_truetype)
  io         картинки, проект .agf, пути UTF-8 на Windows
  brush      формы отпечатков и динамика кистей
  gradient   градиенты и наборы
  effects    стили слоя, евклидово преобразование расстояний
  retouch    размытие/резкость/палец/осветлитель/затемнитель/губка, восстановление
src/app/    программа: окно, панели, инструменты
  main.cpp          SDL + OpenGL + ImGui, главный цикл
  editor.cpp        документ, экранная текстура, команды меню
  editor_tools.cpp  инструменты и живой предпросмотр
  editor_ui.cpp     меню, панели, горячие клавиши
  editor_dialogs.cpp  новый документ, стиль слоя, кривые, фильтры, заставка
  file_dialog.cpp   системные диалоги или встроенный браузер
  clipboard.cpp     буфер обмена Windows (PNG и CF_DIB)
  platform.cpp      Android: выбор файла и сохранение в галерею через JNI
android/            Gradle-проект: активити на базе SDLActivity, манифест, иконки
  icons.cpp         иконки инструментов
```

Мазок кисти сначала рисуется в отдельную маску покрытия и только при отпускании мыши переносится
в слой. Поэтому мазок с непрозрачностью 50% не темнеет на пересечениях, а отмена убирает его целиком.
Сведение слоёв для экрана пересчитывает только изменившийся прямоугольник и раскладывается по всем
ядрам процессора.
