# «Слово защиты»: контракт между модулями

Это пиксельная судебная игра. Игрок всегда **адвокат защиты**, дела рассматриваются в Высшем суде Калифорнии (Superior Court of California, County of Los Angeles), статьи реальные. Весь текст игры на русском, имена американские (пишутся по-русски: «Дэниел Рид»).

Над игрой работают 5 параллельных исполнителей и интегратор. Каждый отвечает за **один файл в `src/`** и не трогает чужие. Общее ядро лежит в `src/core.js`: прочитай его целиком перед началом.

## Технические правила (для всех)

- Внутреннее разрешение **384×216**. Всё рисуется в буфер `G.ctx` попиксельно, на экран он масштабируется без сглаживания.
- **Только пиксель-арт, нарисованный кодом с нуля**: карты-строки (`G.fromMap`), примитивы (`G.rect`, `G.px`, `G.line`, `G.poly`, `G.ellipse`, `G.dither`), процедурная прорисовка по пикселям. Запрещены: загрузка внешних картинок, `ctx.arc`/`ctx.stroke`/градиенты/тени/фильтры/сглаженный текст canvas/`fillText`, дробные координаты, масштабирование спрайтов при рисовании (кроме камеры мира).
- **Палитра только из `G.RAMP` и `G.PAL`** (core.js). Полупрозрачность допустима только для теней и света (`globalAlpha` 0.2–0.5) и для затемнений. Переходы тонов делаются ступенями рампы и дизерингом `G.dither`, а не градиентом.
- Стиль: свет падает **сверху слева** (окна зала на левой стене). Контур `G.PAL.outline` (селективный: на освещённой стороне можно рампой потемнее). На форму 3–4 тона и блик. Без «подушечного» затенения. Объём строится чёткими плоскостями, как у резных деревянных панелей.
- Псевдо-3D: изометрия 2:1 (одна клетка = 32×16 px; линии 2 px вбок на 1 px вниз) для общего плана зала. Крупные планы рисуются в перспективе 3/4 «снизу-сбоку», как кадр кинокамеры.
- Пререндер: всё статичное рисуй один раз в offscreen-canvas (`G.makeCanvas`/`G.makeSprite`) при инициализации и потом только делай blit. Каждый кадр должен рисоваться быстро.
- Модуль это IIFE: `(function(){ const G = window.G; ... })();`. Модули не зависят друг от друга, только от core.js. Исключение: UI может вызывать `G.Font`, а сцены меню могут вызывать `G.Env`/`G.Cast`/`G.Audio`, если они есть (проверяй `if (G.Env)`).
- Порядок загрузки: `core.js, env.js, cast_main.js, cast_case.js, font.js, ui.js, audio.js, cases.js, director.js, main.js`.
- **Проверка обязательна.** Сделай тестовую страницу `test/<модуль>.html`: она подключает `../src/core.js` и свой модуль, рисует галерею/кадр через `G.renderOnce` и ставит `window.__ready = true`. Снимок: `node tools/shot.js test/<модуль>.html /tmp/<...>.png 3` (печатает ошибки страницы). **Смотри на снимки** (Read по png) и доводи арт до качества. Делай несколько итераций: первая версия почти всегда выглядит плохо.
- Не коммить в git, это сделает интегратор.

### Эмоции бюстов (`o.emo`)
Все персонажи с бюстом поддерживают `normal`. Флаг `o.talking` открывает и закрывает рот (2–3 кадра, ~8 кадров/с). Моргание идёт всегда, по таймеру от `o.t`. Дыхание: 1 px подъём плеч с периодом ~3 с.
- `player`: normal, think (рука у подбородка), confident (усмешка), shocked (пот, зрачки маленькие), point (указывает пальцем вперёд, вся поза), slam (руки на стол).
- `judge`: normal, stern (сдвинутые брови), surprised, smile. Анимация `gavel` (замах и удар молотком, ~0.9 с; удар на 0.45 с).
- `prosecutor`: normal, smirk, angry, shocked, point. Анимация `slam` (удар ладонями по столу, ~0.6 с).
- Свидетели: normal, nervous (пот), angry, shocked, breakdown (финальный срыв: свой яркий образ для каждого, например у Холлиса слетает фуражка). Анимация `breakdown` (~1.2 с), после неё держится эмоция breakdown.
- Подсудимые: normal, worried, hopeful, relieved (плачет от облегчения/улыбается).
- `clerk`, `bailiff`, `foreperson`: normal (+talking).

Изометрия (`o.pose`: `stand`|`sit`, `o.dir`: `l`|`r` — смотрит влево-вниз или вправо-вниз): фигура ~12×26 px стоя. В `sit` рисуется верх тела ~14 px (ноги скрыты столом). У `judge` в изометрии есть анимация `gavel`. Если `o.talking` — небольшое покачивание или жест.

## G.Env (src/env.js): окружение

```js
G.Env = {
  world: { w, h },                  // размер изометрического мира в px (~560×320)
  spots: { judge:{x,y,pose:'sit',dir:'r'}, witness:{...}, defense:{...}, defendant:{...},
           prosecution:{...}, clerk:{...}, bailiff:{...}, jury:[{x,y,...}×6], gallery:[{x,y}×8] },
  // точки ступней персонажей в мировых координатах
  drawWorld(ctx, layer, t),         // layer: 'back' (пол, стены, мебель позади людей) | 'front' (передние панели столов, перила, всё, что перекрывает людей)
                                    // рисует в мировых координатах; камеру уже применил вызывающий (G.applyCam)
  cams: { wide:{x,y,z}, judge:{...}, witness:{...}, defense:{...}, prosecution:{...}, jury:{...} }, // готовые позиции камеры в мире
  shots: { judge, witness, defense, prosecution, jury, visit, defendant },
  // крупные планы 384×216: каждый = { anchor:{x,y}, flip:bool, extras?:[{x,y}] }
  // anchor — нижняя середина бюста; flip — зеркалить ли бюст (бюсты рисуются лицом ВЛЕВО-вперёд, т.е. смотрят на левую часть экрана)
  drawShot(ctx, shotId, layer, t),  // layer 'back' | 'front' (стойка/стол перед бюстом, внизу кадра)
  drawExterior(ctx, t),             // фасад здания суда для меню (полный экран 384×216, анимированные облака/флаги/голуби)
};
```
Требования к залу. Изометрический зал Высшего суда Лос-Анджелеса, вид сверху сбоку:
- деревянные стеновые панели (walnut), светлая штукатурка, высокие окна на левой стене с косыми лучами света и пылинками;
- судейская кафедра на возвышении (bench) по центру сзади, за ней Большая печать штата Калифорния, флаги США и Калифорнии на древках;
- место секретаря сбоку от кафедры, свидетельская трибуна (witness stand) рядом с кафедрой;
- скамья присяжных (12 мест в 2 ряда) справа; столы защиты и обвинения напротив кафедры; барьер (bar) с калиткой; ряды скамеек для публики; ковёр, часы на стене.

Крупные планы рисуются в перспективе, с глубиной и светом:
- `judge`: вид снизу на кафедру, печать штата, флаги, табличка «HON. H. WHITAKER»;
- `witness`: трибуна с микрофоном на гибкой ножке, панели;
- `defense`, `prosecution`: стол с бумагами, папками, стаканом воды и ноутбуком, на фоне зал (размыто только плоскими тонами, без blur). Защита стоит слева и смотрит вправо, обвинение справа и смотрит влево;
- `jury`: присяжные в два ряда (рисуются прямо в бэкграунде, разные силуэты);
- `visit`: комната свиданий в окружной тюрьме, стекло, телефонная трубка;
- `defendant`: подсудимый за столом защиты.

## G.Cast (src/cast_main.js и src/cast_case.js): персонажи

`cast_main.js` регистрирует player, judge, prosecutor, clerk, bailiff, juror1..6, foreperson **и иконки улик** (см. ниже). `cast_case.js` регистрирует lomax, hollis, whitfield, crane, park, bell, doyle, morales, holloway.

Регистрация описана в core.js (`G.Cast.register`). Размер бюста: примерно **110×130 px**, голова ~36 px в высоту. Бюст по пояс, нижний край обрезан ровно (его прячет передний слой кадра). Бюсты смотрят **влево-вперёд** (3/4); зеркалит вызывающий через `o.flip`. Реализация `bust.draw` сама применяет flip.

Качество важнее количества: детальные лица (брови, веки, нос, тени скул), складки одежды, блики на очках, волосы прядями. Каждый кадр эмоции отрисовывается заранее.

## G.Font и G.UI (src/font.js, src/ui.js): интерфейс

`font.js`: пиксельные шрифты **с нуля**, полная кириллица (А–Я, а–я, Ё, ё), латиница, цифры, знаки `. , ! ? : ; - — – « » " ' ( ) / % № § $ + = * … #  @ &`.
```js
G.Font = { draw(ctx, text, x, y, color, o), measure(text, o) -> px, wrap(text, maxW, o) -> [lines], lineH }
// o = { font:'small'|'big'|'title', shadow:color, align:'left'|'center'|'right', maxChars:n (для печатания) }
// small: ~5×8 (высота строки 10) — диалоги; big: ~8×11 — заголовки; title: ~ 16 px высоты, жирный, для логотипа и печатей
```

`ui.js`: компоненты и экраны меню.
```js
G.UI = {
  // Диалог: нижняя панель ~384×64, табличка с именем, текст печатается (shown — сколько символов видно),
  // мигающий индикатор «далее», когда waiting.
  drawDialog(ctx, { name, text, shown, waiting, t, side:'left'|'right', color }),
  // Кнопка: возвращает true, если по ней кликнули в этом кадре (использует G.input)
  button(ctx, rect{x,y,w,h}, label, o{kind:'normal'|'primary'|'danger', disabled, hotkey, icon}) -> bool,
  // Шкала доверия: 5 сегментов (печати-медали)
  drawCredibility(ctx, x, y, value, max, t, o{flashLost}),
  // Папка дела (оверлей): список улик (иконки G.Icons), выбор, описание.
  // state = {open, sel, page, mode:'view'|'present'} ; возвращает {action:'present'|'close'|null, id}
  courtRecord(ctx, state, evidence[{id,name,icon,desc,doc?}], t) -> {action, id},
  // Документ на весь экран: лист бумаги с текстом, печатями, подписями чернилами
  drawDocument(ctx, doc{title, header, lines[], stamps:[{text,x,y,color,angle}], signature}, t),
  // Печать (штамп) с двойным контуром, неровной мастикой, наклоном (угол заранее отрисован пиксельно)
  drawStamp(ctx, x, y, text, color, o{angle:-15..15, size:'small'|'big', t:0..1 появление}),
  // Большой «удар печатью» поверх экрана (~0.9 с, t: 0..1): огромный штамп падает с увеличения, мастика
  // разлетается брызгами, листы бумаги колышутся. НЕ речевой пузырь (не копируем чужие игры).
  // kind: 'objection' («ПРОТЕСТ!», красный), 'contradiction' («ПРОТИВОРЕЧИЕ», красный),
  //       'sustained' («ПРОТЕСТ ПРИНЯТ», синий), 'overruled' («ПРОТЕСТ ОТКЛОНЁН», синий), 'evidence' («ПРИОБЩЕНО К ДЕЛУ», синий)
  drawShout(ctx, kind, t),
  // Выбор из вариантов (2–4 кнопки по центру) -> индекс или -1
  choice(ctx, prompt, options[str], t) -> int,
  // HUD перекрёстного допроса: «Показание 2/5», стрелки, кнопки «Уточнить» и «Предъявить», заголовок показаний
  crossHUD(ctx, { title, index, total, statement, t }) -> {action:'prev'|'next'|'press'|'present'|'record'|null},
  // Переходы: шторка/жалюзи — p 0..1
  drawWipe(ctx, p, kind:'blinds'|'iris'),
  // Сцены меню
  TitleScene,        // главное меню на фоне G.Env.drawExterior: Новая игра / Продолжить / Выбор дела / Настройки / Об игре
  CaseSelectScene,   // папки дел (G.Cases) со штампами «ОПРАВДАН(А)» по G.Save.data.solved; закрытые — серые с замком
  SettingsScene,     // громкость музыки/звука, скорость текста — в G.Save.data.settings
  CreditsScene,
};
```
Сцены меню начинают игру вызовом `G.startCase(index)` (его даёт director.js) и возвращаются в меню через `G.setScene(G.UI.TitleScene)`. Музыка меню: `G.Audio && G.Audio.music('menu')`, клики: `G.Audio && G.Audio.sfx('select')`.

## G.Cases (src/cases.js): сценарий

Массив из 4 дел. Формат:
```js
G.Cases = [{
  id: 'violin',
  title: 'Скрипка Гварнери',             // название дела для меню
  docket: 'BA-512874',                   // номер дела (реалистичный формат LA)
  caption: 'Народ штата Калифорния против Сэмюэла Ломакса',
  charges: [{ code: 'Cal. Penal Code § 487(a)', title: 'Хищение в крупном размере (grand theft)', text: 'Точный пересказ статьи по-русски', max: 'до 3 лет' }],
  defendant: 'lomax',
  witnesses: ['hollis'],
  victim: '...',
  date: '14 октября 2025',
  summary: 'Абзац для папки дела',
  evidence: { id: { name, icon, desc, doc?:{title, header, lines:[], stamps:[], signature} } },
  start: ['id', ...],                      // улики на начало
  script: [ ...команды... ],               // главный сценарий дела, исполняется сверху вниз
  testimonies: { t1: { witness, title, statements: [ { text, press:[...команды], hit:'evidenceId'|null, hitScript:[...], add:'evidenceId'? } ], wrong:[...команды]?, loopLine?:'...' } },
}]
```
Команды (`{c:'...'}`):
- `{c:'say', who, text, emo?, anim?, shot?}` — реплика. `who`: id из каста или `'player'`. Без `shot` камера выбирается по говорящему (judge→judge, prosecutor→prosecution, player→defense, свидетель→witness, подсудимый→defendant). В тексте разрешено `*слово*` (выделить красным) и `{p}` (пауза 0.4 с).
- `{c:'think', text}` — внутренний голос игрока (курсив/синий).
- `{c:'narrate', text}` — текст без говорящего (место, время).
- `{c:'shot', id}` — крупный план; `{c:'wide'}` — изометрический общий план; `{c:'cam', id}` — изометрическая камера к точке из `G.Env.cams`.
- `{c:'music', id}` — `menu | court | cross | pressure | victory | defeat | suspense | silence`.
- `{c:'sfx', id}` — `gavel | gavel3 | objection | stamp | paper | evidence | crowd | crowdHush | door | damage | shock | slam | select | cancel | typewriter | heartbeat | jail`.
- `{c:'shout', who, kind}` — `objection | contradiction | sustained | overruled | evidence` (большой штамп поверх экрана, см. G.UI.drawShout).
- `{c:'anim', who, id}` — одноразовая анимация (`gavel`, `slam`, `breakdown`).
- `{c:'enter', who, spot}` / `{c:'leave', who}` — кто где сидит или стоит в изометрическом зале.
- `{c:'evidence', id}` — добавить улику (с показом).
- `{c:'doc', id}` — показать документ улики на весь экран.
- `{c:'title', text, sub}` — титр на чёрном фоне («ВЫСШИЙ СУД КАЛИФОРНИИ / Зал 112, 9:30»).
- `{c:'testimony', id}` — перекрёстный допрос до победы.
- `{c:'present', prompt, answer:'evidenceId', ok:[...], fail:[...]}` — «Предъявите улику, которая доказывает…».
- `{c:'choice', prompt, options:[{text, ok:true|false, then:[...]}]}` — выбор (неверный ответ отнимает доверие и повторяет выбор).
- `{c:'objection', by:'prosecutor', ground:'Слухи — Evidence Code § 1200', ruling:'sustained'|'overruled'}` — протест обвинения с решением судьи.
- `{c:'penalty'}` — минус одна печать доверия.
- `{c:'verdict', result:'not_guilty'}` — финальная сцена: старшина зачитывает вердикт, судья бьёт молотком, штамп.
- `{c:'wait', s}`.

Дело строится как реальный процесс: вступление (титр, встреча с клиентом в `visit`), открытие заседания, вступительная речь обвинения, приведение свидетеля к присяге секретарём, прямой допрос, перекрёстный допрос игрока (2–3 показания с противоречиями), протесты с решениями судьи, неожиданный поворот, финальный срыв свидетеля, вердикт присяжных, удар молотка.

## G.Audio (audio.js, интегратор)
`G.Audio.music(id)`, `G.Audio.sfx(id)`, `G.Audio.blip(voice)`, `G.Audio.unlock()`.

## Director (director.js, интегратор)
Исполняет сценарии, рисует зал и крупные планы, вызывает UI. Даёт `G.startCase(i)`.

## ДОПОЛНЕНИЕ v2 (обязательно): живой зал, реакции, получение улики

**Постоянная жизнь в кадре.** Всё время что-то происходит. Каждый персонаж дышит (1–2 px, период 2.5–4 с, у каждого своя фаза: бери её из хэша id или x). Люди моргают, переминаются, поправляют очки и бумаги, кашляют. Присяжные и зрители в изометрии иногда поворачивают голову, шепчутся с соседом, что-то пишут. Стенографистка печатает. Флаги колышутся, пылинки летают, вентилятор под потолком крутится, часы идут.

**Реакции толпы** (изометрия, `o.react` в `G.Cast.drawIso`, с `o.reactT` — сколько секунд идёт реакция):
`whisper` (наклон к соседу в сторону `o.dir`, рука у рта), `gasp` (руки к лицу, подпрыгивание на 1 px), `murmur` (качают головой), `angry` (кулак вверх, трясётся, красное лицо), `cheer` (руки вверх, подпрыгивают), `clap` (хлопают, 2 кадра), `laugh` (трясутся), `shout` (рот открыт, рука рупором). Есть у всех `juror1..6`, `foreperson` и новых зрителей `spectator1..12` (только изометрия: репортёр с блокнотом, судебный художник с планшетом, пожилая пара, студенты, родственники в трауре, мужчина в кепке и т. д.). Новый персонаж `reporter` — судебная стенографистка (бюст не нужен, только изометрия, `sit`, постоянно печатает). В основном толпа **шепчется**. Злость и ликование бывают только после вердикта, срыва свидетеля или громкого поворота.

**Новые команды сценария:** `{c:'crowd', mood:'whisper'|'gasp'|'murmur'|'angry'|'cheer'|'clap'|'laugh'|'shout', lines?:['Не может быть!', ...]}`. Режиссёр делает общий план или оставляет текущий, запускает реакции у присяжных и зрителей и показывает над ними пиксельные реплики-пузыри. После этого обычно идёт `{c:'anim', who:'judge', id:'gavel'}` и «Тишина в зале!».

**G.UI.drawSpeech(ctx, x, y, text, t)** — маленький пиксельный пузырь-реплика над головой в экранных координатах (хвостик вниз, появление «pop»).

**G.UI.drawItemGet(ctx, ev{id,name,icon,desc}, t)** — кинематографичное получение улики, ~2.4 с (t в секундах): экран темнеет дизерингом, за предметом вращаются лучи света, предмет поднимается снизу и замирает над головой, сыплются искры, затем выезжает лента «НОВАЯ УЛИКА» и название. Документы и письма выезжают снизу экрана как плоские 2D-листы, на них сверху падает печать. Свой мотив оригинальный, ничего не копировать. Звук `sfx('itemget')` даёт аудиомодуль.

**G.Icons.drawBig(ctx, id, x, y)** — большие версии улик 64×64 (отдельно нарисованные, не увеличенные), для получения улики и описания в папке.

Улики и письма в игре — это 2D-предметы и листы, а не изометрия.

# КОНТРАКТ v3 (заменяет противоречащие пункты выше)

## 1. Всё — отдельные PNG-ассеты
Код теперь служит **генератором**. Каждый статичный кадр создаётся только через
`G.cacheCanvas(key, w, h, fn)` (см. core.js), а не через `G.makeSprite`/`G.fromMap` напрямую в рантайме.
Ключ — это путь файла без расширения, латиницей, через `/`:
`cast/judge/bust/stern/f0`, `iso/judge/sit/l/f1`, `env/world/back`, `env/shot/judge/back`, `icon/violin/64`, `ui/stamp/objection`.
`tools/bake.js` запускает игру, вызывает все `G.prebuild(fn)` и сохраняет каждый ключ как `assets/png/<key>.png`, а потом пакует атласы.
Игра грузит атласы, и `G.cacheCanvas` отдаёт уже запечённую картинку. **Каждый модуль обязан зарегистрировать `G.prebuild(() => {...})`, который вызывает все свои ключи** (все эмоции, кадры, направления и позы). Результат `cacheCanvas` можно только рисовать (`drawImage`), читать из него пиксели нельзя. Комбинировать слои (тело, голова, глаза, рот) можно и нужно: так меньше файлов и больше вариантов.

## 2. Крупные портреты (бюсты): новый стиль
- Рисуются в **половинном разрешении**: родной бюст ~**60×70 px**, голова ~20–22 px. В кэш кладётся увеличенная ×2 копия (каждый пиксель 2×2), рантайм просто рисует её. Видимый размер ~120×140, якорь — нижняя середина, как раньше. Пиксели крупнее, но деталей больше.
- **Не раздувать фигуры.** Пропорции естественные: голова к ширине плеч ~1 : 2.4–2.7, приталенная одежда, видимые руки и кисти.
- Настоящий пиксель-арт: рампы со сдвигом оттенка, чистые кластеры, без «подушечного» затенения и шума, ручной AA по минимуму, читаемый силуэт. Ориентир — портреты в лучших инди-играх. Свет сверху слева.
- **Игрок (`player`)**: лицо и волосы **в глубокой тени** (тёмный силуэт головы из 2 тёмных тонов + 1 px контровой свет), черт лица нет. Костюм, галстук, значок, руки и позы детальные, эмоции передаются языком тела: point, slam, think, confident, shocked (отшатнулся, пот блестит на силуэте), normal.
- Дыхание (1 родной px = 2 экранных, у каждого своя фаза), моргание, рот при разговоре (3 кадра), фиджеты, анимации (gavel, slam, breakdown) — как в v1/v2.

## 3. Маленькие (изометрические) персонажи и иконки
Отдельный файл `src/iso.js` (грузится после cast_case.js) переопределяет `G.Cast.defs[id].iso` для **всех** персонажей. Лица на мелком масштабе: глаза — 1 тёмный пиксель (или 2 в ряд), рот только при разговоре или реакции, без грязных пикселей. Тон кожи 2–3 ступени, волосы — чёткие формы. `src/icons.js` переопределяет `G.Icons`: все 30 улик заново, 32 и 64 px. Скрипка с 4 струнами, грифом, колками, завитком, эфами, подставкой и подбородником.

## 4. Новые данные сценария (cases.js)
- `charges[i].edition` — «Cal. Penal Code § 487(a), ред., действующая на 1 января 2025 г.» (год редакции обязателен). Где известен закон о последних изменениях — указать (например, SB 1437 (2018) для § 187). Не выдумывать то, в чём нет уверенности: писать «ред., действующая на 2025 г.».
- В показании `hit` может быть массивом альтернатив: `alts: [{ ev:'id', label:'короткая суть линии', hitScript:[...], effects:{judge,jury,public,press} }]`. Каждая альтернатива — **юридически обоснованная линия защиты** со своим продолжением и последствиями. Старое `hit` + `hitScript` остаётся основной линией.
- Новая команда **конструктор аргумента**:
  ```js
  {c:'argue', prompt:'…', claims:[{id,text}], grounds:[{id,text,law:'Evid. Code § 1200 (ред. 2025)'}],
   proof:true,                         // нужно ли приложить улику
   routes:[ {claim, ground, ev, label, effects:{…}, then:[…]} ],   // 2–4 ВЕРНЫХ варианта, разные юридические пути
   weak:[ {claim, ground, ev, then:[…], effects:{…}} ],             // слабые: проходят, но с минусом
   fail:[…] }                                                       // остальное — штраф доверия
  ```
  Игрок сам собирает мысль: **тезис + правовое основание + доказательство**. Неподходящая комбинация отклоняется судьёй с объяснением.
- `{c:'effect', judge:+2, jury:+1, public:-1, press:+3}` — сдвиг мнений (−10..+10).
- `{c:'remarks', pool:'id', mood:'whisper|gasp|angry|cheer|laugh|shout', n:3}` — внезапные реплики зала по краям экрана. Это не диалог: они всплывают сами и не ждут клика.
- `{c:'silence'}` — мгновенная тишина: музыка замирает, зал замолкает, судья смотрит поверх очков.

## 5. Реплики зала (src/remarks.js)
`G.Remarks = { pools: { id: [строки] }, adult: { id: [строки] }, generic: { whisper:[], gasp:[], angry:[], cheer:[], laugh:[], shout:[], silence:[] } }`.
Нужно много вариантов. Режим «взрослый язык» в настройках добавляет `adult` (обычный мат и грубости: «дерьмо», «сука», «чёрт», «мать твою», «блядь», «херня», «урод»). **Запрещены оскорбления по расе, национальности, ориентации, религии, инвалидности.** В обычном режиме мата нет.

## 6. Интерфейс
- Реплики зала: `G.UI.drawCrowdBubble(ctx, b)`, где `b = {text, x, y, side:'l'|'r', age, life}`. Пузырь плавно проявляется (прозрачность 0→1 за 0.35 с), висит и в конце **сжимается в точку** с затуханием. Пузыри у левого и правого краёв не перекрывают друг друга (раскладку делает режиссёр), по ширине подстраиваются под текст. Пустой текст не рисуется.
- Шрифт должен читаться: настройка «Размер текста: обычный / крупный» (крупный — диалог шрифтом big в более высокой панели).
- Китайский: `G.FontCJK` (атлас глифов 12 px, готовит интегратор). `G.Font.draw/measure/wrap` должны для символов CJK брать глифы из `G.FontCJK`, если он есть, и переносить строки по символам.
- Все строки интерфейса берутся через `G.T('key')`. Словари: `src/locale/ui_strings.js` (`G.UIStr.ru`, `G.UIStr.en`).

## 7. Репутация (src/reputation.js, интегратор)
`G.Rep.compute()` возвращает `{ total, cases:[{id,title,result:'win'|'loss',score,parts:[{label,value}]}], opinions:{judge,jury,public,press}, history:[…] }`.
За выигранное дело «+», за проигранное «−», формула раскладывается на слагаемые.
