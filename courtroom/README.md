# Слово защиты

Пиксельная судебная игра. Вы адвокат защиты Дэниел Рид в Высшем суде Калифорнии (округ Лос-Анджелес). В игре четыре дела по реальным статьям Уголовного кодекса Калифорнии: перекрёстные допросы, улики, протесты по Кодексу о доказательствах, вердикт присяжных и удар судейского молотка.

Вся графика нарисована кодом попиксельно: изометрический зал суда, крупные планы, анимированные персонажи, пиксельный шрифт с кириллицей. Музыка и звуки синтезируются в реальном времени через WebAudio по нотам, записанным в `src/audio.js`.

## Запуск

- Открыть `index.html` в браузере (версия для разработки, скрипты подключаются по отдельности).
- Или собрать один файл: `node tools/build.js`. Результат появится в `dist/play.html`.

## Управление

| Действие | Мышь / касание | Клавиатура |
|---|---|---|
| Дальше по тексту | клик | Enter / Пробел |
| Листать показания | стрелки на экране | ← → |
| Уточнить показание | «Уточнить» | Q |
| Предъявить улику | «Предъявить» | E |
| Пауза | — | Esc |

## Устройство

| Файл | Что внутри |
|---|---|
| `src/core.js` | движок: буфер 384×216, палитра, примитивы, ввод, сцены, камера, сохранения |
| `src/env.js` | изометрический зал суда, крупные планы, фасад суда |
| `src/cast_main.js` | адвокат, судья, прокурор, секретарь, пристав, присяжные, иконки улик |
| `src/cast_case.js` | подсудимые и свидетели четырёх дел |
| `src/font.js`, `src/ui.js` | пиксельные шрифты, диалоги, папка дела, документы, печати, меню |
| `src/audio.js` | синтезатор, трекер и 7 музыкальных тем, звуковые эффекты |
| `src/cases.js` | сценарии дел |
| `src/director.js` | режиссёр процесса: исполняет сценарии |

Контракт между модулями описан в `CONTRACT.md`. Автотест проходит дело целиком и сохраняет снимки: `node tools/autoplay.js 0 /tmp/auto`.
