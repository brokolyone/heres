# Краш-полигон К-7

Браузерная игра для ПК (клавиатура и мышь) про машины с деформацией кузова. Вместо карт тут испытательный полигон:
разгонная прямая с разметкой дистанции, бетонный барьер, столб Ø254 мм, вторая машина для бокового удара,
трамплин, кикер для опрокидывания, слалом из конусов, бочки, шины, отбойники и мачты освещения.

Запуск: открыть `index.html` в браузере (нужен интернет, three.js и cannon-es грузятся с jsDelivr)
или поднять любой статический сервер: `python3 -m http.server` в этой папке.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D / стрелки | газ, тормоз/задний ход, руль |
| Пробел | ручник |
| B | тип теста: барьер 100%, перекрытие 40%, столб, боковой удар |
| Q / E | скорость теста (30–120 км/ч) |
| C | запустить краш-тест на новой машине |
| R | новая машина для свободного заезда |
| F | поставить машину на колёса |
| T | замедление времени |
| V | камера: погоня / капот / облёт |
| H | показать или скрыть подсказку по клавишам |
| Мышь | клик захватывает курсор для обзора (Esc отпускает), колесо меняет дистанцию камеры |
| Enter / клик | начать с заставки |

## Как устроены повреждения

- Кузов собирается из поперечных сечений (лофт), панели — отдельные меши: капот, двери, бамперы, крышка багажника, стёкла, фары, зеркала.
- При ударе берётся точка и нормаль контакта, скорость сближения и масса препятствия. Глубина смятия считается из энергии:
  мягкая зона (≈0,65 м) сминается первой, дальше силовая клетка салона с жёсткостью ×2,2.
- Плоскость смятия вдавливается в кузов и обрезается по форме препятствия: стена мнёт весь передок, столб даёт узкую глубокую вмятину, машина — округлую.
- Металл складывается наружу (капот горбится, крылья расходятся), есть шум «гармошки» и потемнение смятых мест.
- Панели копят повреждения и отрываются, становясь физическими обломками. Боковые стёкла рассыпаются, лобовое трескается (триплекс).
- Колёса гнутся (развал, увод руля) и отрываются, двигатель теряет мощность и дымит.
- Коллайдер передка укорачивается после смятия, поэтому повторный удар идёт глубже.

После краш-теста внизу экрана выходит протокол (закрывается клавишами движения или Esc): скорость удара, остаточная деформация, проникновение в салон, пиковое замедление и график импульса.
