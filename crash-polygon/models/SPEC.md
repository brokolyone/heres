# Модели полигона: общая спецификация

Пять агентов делают **одну** машину и **один** полигон. Каждый владеет только своим файлом.
Чужие файлы, `index.html`, `common.js` и `baseline/` не трогать. Если нужен новый хук в игре или новая общая
константа, напиши об этом в итоговом отчёте, интегратор добавит.

| Файл | Владелец | Что внутри |
|---|---|---|
| `engine.js` | агент «моторный отсек» | двигатель, коробка, радиатор, вентилятор, АКБ, впуск, выпускной коллектор, патрубки, бачки, моторный щит, передние лонжероны и подрамник |
| `wheels.js` | агент «колёса и подвеска» | шина с протектором, диск, гайки, тормозной диск и суппорт, стойки, пружины, рычаги, поворотные кулаки, рулевые тяги |
| `interior.js` | агент «салон и днище» | сиденья, приборная панель, руль и колонка, педали, тоннель, ремни, манекены, подушки безопасности; днище: пол, пороги, кардан, задний мост (привод задний), выхлоп с глушителем, бензобак |
| `fluids.js` | агент «жидкости и последствия» | масло, антифриз, топливо, тормозная жидкость: капли, струйки, лужи на земле; пар, дым, возгорание |
| `environment.js` | агент «окружение» | барьер, столбы, мачты, отбойники, трамплины, ангар, вышка, контейнеры, конусы, бочки, шины, дальний пейзаж |

## Стиль (общий для всех)

- Low-poly, `flatShading: true`, но **точные пропорции реальных агрегатов** и достаточно деталей, чтобы узнавалось, что это.
  Не игрушка и не набор кубов. Ориентир: седан C-класса, рядная «четвёрка» стоит **продольно**, привод задний.
- Материалы через `STD(color, opts)` из `common.js`, цвета из `PALETTE`, приглушённые. Металл: metalness 0.3–0.8, резина и пластик: roughness 0.8–0.95.
- **Никакого текста нигде**: ни надписей, ни цифр, ни логотипов в текстурах.
- Тени: `castShadow` для заметных деталей, мелочь без теней.
- Бюджет треугольников: моторный отсек ≤ 8k, одно колесо в сборе ≤ 1.5k, подвеска ≤ 3k, салон+днище ≤ 10k, окружение всего ≤ 150k (используй `InstancedMesh` и общую геометрию).
  Машин на сцене бывает две.

## Система координат машины

- Кадр шасси: **+z вперёд, +y вверх, +x — ЛЕВЫЙ борт**. Начало = центр тела, на высоте `CG ≈ 0.665` м над землёй в покое.
- `gy(h)` переводит высоту над землёй в y кадра шасси. Удобно положить свою группу с `position.y = -CG` и строить в высотах над землёй.
- `bodySection(z)` даёт контур кузова в сечении z (низ, линия окон, верх, полуширина). Всё внутри кузова должно помещаться в этот контур.
- `archTop(z)` — верх колёсной арки. Колёса: центры в `WHEELS` (x ±0.79, z +1.33 / −1.28), радиус 0.33, ширина 0.22.
- Кузов от z −2.15 (зад) до +2.15 (перед). Моторный щит z ≈ 0.95, капот от 0.97 вперёд, окно B-стойки около z −0.34.

### Зоны (чтобы детали не пересекались)

| Зона | z | высота над землёй | |x| | владелец |
|---|---|---|---|---|
| моторный отсек | 0.97…2.08 | 0.20…0.88 | ≤ 0.72 (у колёс при z 0.85…1.80 только ≤ 0.50) | engine |
| подвеска передняя/задняя | ось ±0.45 | 0.10…0.75 | 0.40…0.80 | wheels |
| салон | −1.15…0.95 | 0.24…1.36 | ≤ 0.80 | interior |
| днище | −2.0…2.0 | 0.06…0.24 | ≤ 0.72 (кроме зон колёс) | interior |
| утечки | точки задают владельцы агрегатов | | | fluids рисует |

## Модули машины (engine, wheels, interior, fluids)

Фабрика получает `ctx` и возвращает объект с необязательными методами:

```js
{ update(dt), onImpact(ev), dispose() }            // createEngineBay, createSuspension, createInterior, createFluids
{ group, update(dt, state, wheelInfo), onBreak(), dispose() }   // createWheel(ctx, i) — по одному на колесо
```

`ctx`: `THREE, CANNON, car, group (кадр шасси), scene, fx {puff, spark, shard}, addDebris(mesh, cannonBody), mProp,
groundBody, sound {clunk, glassSound, crashSound}, sys, time()`.

- `ev` (удар): `pL, nL` — точка и нормаль **в кадре шасси** (нормаль направлена ВНУТРЬ машины), `pW, nW` — то же в мире,
  `depth` — глубина смятия, м; `v` — скорость удара, м/с; флаги `frontal, rear, side, roof, scrape`.
- Состояние машины (только читать): `car.frontCrush`, `car.rearCrush` (м, укорочение передка/зада), `car.engine` (0…1, здоровье мотора),
  `car.cabinIntr` (м), `car.zone {F,R,L,Rt,T}`, `car.wheelState[i] {dmg, broken, camber}`, `car.body` (cannon), `car.vehicle.wheelInfos[i]`
  (`suspensionLength`, `steering`, `rotation`, `skidInfo`, `isInContact`), `car.parts` (панели кузова; `part.name`, `part.gone` — капот `hood` мог отлететь).
- Колесо: `group` живёт в мире, игра каждый кадр копирует в него трансформ колеса из cannon (уже с вращением и поворотом руля).
  Ось колеса — x. Невращающиеся детали (суппорт) компенсируй сами через `wheelInfo.rotation`.
- Отлёт детали: создай `CANNON.Body` (масса, форма) в мировых координатах и вызови `ctx.addDebris(mesh, body)`; меш убери из своей группы.

### Общая доска `car.sys` (так модули работают над одной машиной)

| ключ | кто пишет | смысл |
|---|---|---|
| `sys.leaks` | engine, wheels, interior | массив `{kind:'oil'|'coolant'|'fuel'|'brake', at: THREE.Vector3 (кадр шасси), rate: 0…1}`; добавляй и обновляй свои записи |
| `sys.radiatorBroken`, `sys.engineShift` | engine | радиатор пробит; смещение блока назад, м |
| `sys.fuelTankBroken`, `sys.exhaustLoose` | interior | бак пробит; выхлоп оторван |
| `sys.tyreFlat` | wheels | массив из 4 bool |
| `sys.fire` | fluids | 0…1, пожар |

fluids читает `sys.leaks` и рисует капли/лужи под точками утечки; пар — при `radiatorBroken`, дым — по `car.engine`.
Лужи живут в мире (не удаляются вместе с машиной), не больше ~40, старые затухают. Ставь их на y ≈ 0.006…0.01 с `polygonOffset`.

### Повреждения (обязательно для car-модулей)

Детали не должны торчать сквозь смятый кузов. При фронтальном ударе всё, что впереди `ZF - car.frontCrush`, уезжает назад
или сминается (используй `car.frontCrush` каждый кадр). Тяжёлые удары отрывают навесное (АКБ, бачки, выхлоп, колпаки) в обломки.

## Окружение

Игра сама расставляет объекты и делает коллайдеры. Каждая фабрика возвращает Object3D с началом **в центре коллайдера**
и его ориентацией (размеры коллайдеров в комментариях `environment.js`). Модель должна совпадать с коллайдером по габаритам
(±5 см), иначе машина будет врезаться в воздух. Сигнатуры и экспорты не менять. `scenery(scene)` может добавлять
декор без коллайдеров только **за пределами площадки** (|x| > 125 или |z| > 155) и плоские детали на земле.

## Проверка

```sh
(cd crash-polygon && python3 -m http.server 8765)    # уже может работать, проверь curl localhost:8765
NODE_PATH=$(npm root -g) node crash-polygon/tools/shot.cjs out.png <idle|drive|wall|offset|pole|side> [шаги скорости] [камера] [xray]
```

Камера: `@dx,dy,dz,lx,ly,lz` — относительно машины игрока (мир), `xray` прячет кузов и стёкла, чтобы видеть начинку.
Рендер программный и медленный (1–2 кадра/с), это нормально. В консоли не должно быть ошибок твоего модуля:
если модуль падает, игра пишет `model module ...` и подставляет `baseline/`. Скриншоты и временные файлы — только в
свою папку в `/tmp/claude-0/-home-user-heres/e5924ae8-3065-5446-b6e7-9d641a51a7d5/scratchpad/<твой-модуль>/`.
Не коммить: коммитит интегратор.
