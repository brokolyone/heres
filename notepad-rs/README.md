# notepad-rs: Блокнот Windows на Rust

Классический `notepad.exe`, пересобранный с нуля на Rust. Чистый Win32 через `windows-sys`,
без фреймворков и рантайма. Получается один `.exe` размером около 300 КБ, которому нужны только системные DLL.

## Что умеет

- **Файл:** создать, новое окно, открыть, сохранить, сохранить как. Перед выходом спрашивает про несохранённые изменения.
  Файлы можно перетаскивать в окно и открывать из командной строки (`notepad.exe file.txt`).
- **Правка:** отмена, вырезать, копировать, вставить, удалить, найти (F3 и Shift+F3), заменить, заменить всё,
  перейти к строке (Ctrl+G), выделить всё, время и дата (F5).
- **Формат:** перенос по словам, выбор шрифта, кодировка (UTF-8, UTF-8 с BOM, UTF-16 LE/BE, ANSI)
  и конец строки (CRLF, LF, CR).
- **Вид:** масштаб (Ctrl+Плюс/Минус/0 и Ctrl+колесо мыши), строка состояния
  (строка и столбец, масштаб, конец строки, кодировка).
- Кодировка и концы строк определяются при открытии и сохраняются такими же.
- Фишка оригинала: если файл начинается с `.LOG`, при открытии в конец дописывается время.
- Настройки (шрифт, перенос, строка состояния, положение окна) хранятся в `HKCU\Software\notepad-rs`.
- Есть манифест: визуальные стили Windows и чёткая картинка на HiDPI (Per-Monitor V2).

## Сборка

На Windows:

```
cargo build --release
```

Из Linux (кросс-компиляция):

```
rustup target add x86_64-pc-windows-gnu
sudo apt install gcc-mingw-w64-x86-64     # линкер и windres
cargo build --release --target x86_64-pc-windows-gnu
# → target/x86_64-pc-windows-gnu/release/notepad.exe
```

Тесты ядра (кодировки, концы строк, поиск) работают на любой ОС:

```
cargo test --lib
```

## Устройство

| Файл | Что внутри |
|---|---|
| `src/encoding.rs` | определение BOM, UTF-8 или ANSI, подсчёт концов строк, перевод в CRLF и обратно |
| `src/search.rs` | поиск вверх и вниз, с учётом регистра и целых слов, «заменить всё» (в UTF-16, как EDIT-контрол) |
| `src/win.rs` | окно, EDIT-контрол, меню и горячие клавиши, строка состояния, стандартные диалоги, диалог «Перейти» из шаблона в памяти, реестр |
| `res/` | иконка, манифест, сведения о версии |
| `tools/make_icon.py` | рисует иконку |
