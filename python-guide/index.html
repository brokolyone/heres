по чертежам

Программирование с абсолютного нуля. Каждая идея нарисована как чертёж: стрелки, размеры, выноски. Код запускается прямо здесь, ничего устанавливать не надо.

Начать с листа 00 → Все листы
X 0000 · Y 0000
>>> Привет!

Программа — это список команд для компьютера. Компьютер очень быстрый, но совсем не догадливый: делает ровно то, что написано.

Python — язык, на котором эти команды удобно писать. Он похож на упрощённый английский. На нём пишут школьники, инженеры NASA, аналитики в банках, авторы нейросетей. Куски YouTube и Instagram тоже написаны на Python.

Ты пишешь текст программы. Python читает его строчка за строчкой, сверху вниз, и переводит на язык, который понимает железо. Компьютер выполняет.

Аналогия

Рецепт блинов: «разбей 2 яйца, влей стакан молока, перемешай». Если в рецепте написано «влей стакан бензина», повар-компьютер нальёт. Он не спорит и не исправляет.

Как пользоваться альбомом

Читай лист, смотри чертёж, нажимай кнопки в схемах. Код в чёрно-белых окошках можно менять и запускать кнопкой «Запустить» (или Ctrl+Enter). Ломай смело: компьютер от этого не сломается. В конце листа проверочный вопрос; ответишь верно, лист отметится в оглавлении.

Замени текст в кавычках на своё имя и запусти.
Под капотом

Процессор понимает только машинные коды: числа, обозначающие крошечные операции вроде «сложи два регистра». Писать так долго и мучительно. Python — интерпретируемый язык: программа-интерпретатор читает твой текст и выполняет его сразу, без отдельного шага компиляции.

На этом сайте работает Brython: Python, переписанный так, чтобы жить в браузере. На компьютере ставят обычный CPython с python.org (лист 13).

print() выводит на экран то, что стоит в скобках. С неё начинают все программисты мира.

  • Текст пишут в кавычках: "так" или 'так'. Текст в программировании называют строкой.
  • Числа пишут без кавычек: print(42).
  • Через запятую можно дать несколько значений. Python поставит между ними пробел.
  • Каждый print печатает с новой строки.

Главная ловушка новичка: print("2 + 2") напечатает 2 + 2 буквально, а print(2 + 2) сначала посчитает и напечатает 4. Кавычки означают «не думай, просто покажи».

У print есть необязательные настройки. sep задаёт, что ставить между значениями (по умолчанию пробел). end задаёт, чем закончить (по умолчанию перенос строки \n).

print("Загрузка", end="...") напечатает и останется на той же строке. Внутри строки \n означает перенос, а \t табуляцию.

Переменная — это имя, которое ты вешаешь на значение, чтобы потом к нему обращаться.

age = 12 читается «пусть age будет 12». Знак = здесь означает не «равно», а присвоить: справа значение, слева имя. Сначала Python вычисляет правую часть, потом вешает на результат бирку с именем.

Правила имён:

  • буквы, цифры и _; начинать с цифры нельзя: 2team ошибка, team2 можно;
  • большие и маленькие буквы различаются: Name и name разные;
  • русские имена Python понимает, но в мире принято латиницей: user_name, score.

Бирка на чемодане. Чемодан (значение) лежит на складе (в памяти), а бирка с надписью «age» привязана к нему верёвочкой. Перевесить бирку на другой чемодан можно в любой момент.

В Python переменная не коробка, а ссылка. friend = name не копирует строку: на тот же объект вешается вторая бирка (на схеме это видно). Для чисел и строк разницы почти не заметно. Для списков (лист 09) это очень важно: изменишь список через одно имя, и через второе он тоже изменится.

Значение, на которое не смотрит ни одна бирка, Python выбрасывает сам. Это называется сборкой мусора.

У каждого значения есть тип. От типа зависит, что с ним можно делать.

Целое числоint12 -5 2026
Дробное числоfloat3.14 -0.5 2.0
Строка / текстstr"кот" '12' ""
ЛогическийboolTrue False

Почему это важно: 2 + 2 равно 4, а "2" + "2" равно "22". Строки при сложении склеиваются, числа складываются.

Дробные числа пишут через точку, не через запятую: 3.5. Запись 3,5 Python поймёт как два отдельных числа.

Узнать тип: type(x). Превратить один тип в другой: int("12") даёт число 12, str(12) даёт текст "12", float("3.5") даёт 3.5.

Python — язык с динамической типизацией: тип принадлежит значению, а не переменной. Бирку x можно повесить сначала на число, потом на строку.

bool на самом деле разновидность int: True + True даёт 2. Пустые значения (0, "", []) считаются ложью в условиях.

Python — очень мощный калькулятор. Порядок действий как в школе: сначала скобки, потом степень, потом умножение и деление, в конце сложение и вычитание.

Остаток % полезнее, чем кажется. n % 2 == 0 проверяет, чётное ли число. минуты % 60 даёт минуты сверх целых часов.

0.1 + 0.2 в Python даёт 0.30000000000000004. Это не баг Python: компьютер хранит дроби в двоичном виде, и 0.1 в двоичной системе бесконечная дробь, как 1/3 в десятичной. Для денег используют модуль decimal или считают в копейках.

Целые числа в Python не ограничены по размеру: попробуй print(2 ** 1000).

Строка — это цепочка символов, и у каждого символа есть номер (индекс). Счёт идёт с нуля.

s =
  • s[0] первый символ, s[-1] последний.
  • s[0:6] срез: символы с 0 по 5. Конец в срез не входит, как в линейке: от 0 до 6 сантиметров — это 6 сантиметров.
  • len(s) длина строки.
  • s.upper() большими буквами, s.lower() маленькими, s.replace("а", "о") замена.

f-строки — самый удобный способ вставить значения в текст. Ставишь f перед кавычками и пишешь переменные в фигурных скобках:

f"Мне {age} лет"

Внутри скобок можно даже считать: f"Через год {age + 1}".

Выведи своё имя задом наперёд. Подсказка: срез s[::-1].
Под капотом

Строки неизменяемы: s[0] = "Ж" выдаст ошибку. Методы вроде upper() не меняют строку, а возвращают новую.

У среза есть третье число, шаг: s[::2] берёт каждый второй символ, s[::-1] идёт с конца.

input() останавливает программу и ждёт, пока человек что-нибудь напечатает и нажмёт Enter.

То, что напечатал человек, возвращается как строка. Всегда строка, даже если там цифры. Поэтому для чисел пишут int(input()).

В скобках можно написать вопрос: input("Как тебя зовут? ").

Условие — развилка. Если верно, программа идёт по одной дороге, иначе по другой.

  • if «если», elif «а иначе если», else «иначе».
  • После условия ставится двоеточие :.
  • Строки внутри сдвигаются на 4 пробела. Отступ показывает, что относится к условию.
  • Сравнения: == равно, != не равно, > < >= <=.
  • Соединять: and (и), or (или), not (не).

Одно = вешает бирку, два == сравнивают. Перепутать их — классика.

temp = 18 °C
temp = 18
if temp > 25:
print("Жарко, бери кепку")
elif temp > 10:
print("Нормально, лёгкая куртка")
else:
print("Холодно, надень шапку!")
Напиши программу: спроси число и скажи, чётное оно или нет. Подсказка: число % 2 == 0.
Под капотом

Python проверяет ветки по очереди сверху вниз и выполняет только первую подходящую. Поэтому при температуре 30 программа скажет «Жарко», хотя 30 больше и 10 тоже.

Результат сравнения — значение типа bool: print(5 > 3) напечатает True. Можно записать в переменную: is_adult = age >= 18.

Цикл повторяет действия. Компьютер не устаёт: повторить миллион раз ему так же легко, как один.

for проходит по очереди по каждому элементу. range(1, 6) выдаёт числа 1, 2, 3, 4, 5 (шестёрка не входит, как и в срезах). range(5) выдаёт 0, 1, 2, 3, 4.

while повторяет, пока условие верно. Если условие никогда не станет ложным, цикл будет крутиться вечно. Это называется бесконечный цикл, и вкладка браузера тогда зависнет.

break выходит из цикла досрочно, continue пропускает остаток шага.

Аналогия

Конвейер на заводе: детали едут одна за другой, а робот над лентой делает с каждой одно и то же. Деталь — это i, действие робота — тело цикла с отступом.

Конвейер for
for i in range(1, 6):
print(i, "×", i, "=", i * i)
Выведи все чётные числа от 2 до 20. Подсказка: range(2, 21, 2).
Под капотом

У range бывает третье число, шаг: range(10, 0, -1) считает назад.

Частый приём: накопитель. Перед циклом total = 0, внутри total = total + i (или короче total += i). После цикла в total сумма.

Список — много значений под одним именем, по порядку. Как поезд: у каждого вагона номер, первый вагон под номером 0.

Нажми на вагон, чтобы узнать его индекс
  • Создать: shop = ["хлеб", "молоко", "сыр"]
  • Взять элемент: shop[0], последний: shop[-1]
  • Заменить: shop[1] = "кефир"
  • Добавить в конец: shop.append("яйца")
  • Убрать последний: shop.pop()
  • Длина: len(shop), проверка: "сыр" in shop

Списки и циклы созданы друг для друга:

for item in shop:
    print("Купить:", item)

В списке может лежать что угодно: числа, строки, даже другие списки. Таблица — это список строк, где каждая строка тоже список.

Сделай список из 5 любимых фильмов и выведи каждый с номером. Подсказка: for i, film in enumerate(films, 1).
Под капотом

Помнишь бирки из листа 02? b = a для списка не копирует его. b.append(1) изменит и a, потому что это один и тот же поезд. Копия: b = a.copy().

Генератор списка — короткая запись цикла: [x * x for x in range(5)] даёт [0, 1, 4, 9, 16].

Словарь хранит пары «ключ → значение». Ищешь не по номеру, а по названию.

phone = {"Аня": "111-22", "Петя": "333-44"}

  • Взять: phone["Аня"]
  • Добавить или заменить: phone["Вова"] = "555-66"
  • Безопасно взять: phone.get("Кто-то", "нет") не упадёт, если ключа нет
  • Все ключи: phone.keys(), все значения: phone.values()

Функция — именованный кусок кода, который можно запускать много раз. Кладёшь что-то на вход, получаешь результат на выходе.

def создаёт функцию. В скобках параметры: то, что функция получает. return отдаёт результат обратно.

print, len, input — тоже функции, просто их уже написали за тебя.

Правило программистов: если копируешь один и тот же код третий раз, пора делать функцию.

Под капотом

Переменные, созданные внутри функции, живут только внутри неё (локальная область видимости). Снаружи их не видно.

У параметров бывают значения по умолчанию: def greet(name="друг"). Тогда greet() сработает и без аргумента.

Функция без return возвращает специальное значение None — «ничего».

Ошибки — нормальная часть работы. Опытный программист ошибается не реже новичка, просто быстрее читает сообщение.

Traceback (most recent call last):  File "main.py", line 3, in <module>    print("Мне " + age + " лет")TypeError: can only concatenate str (not "int") to str
  1. Traceback — «путь до места аварии». Читать снизу вверх.
  2. line 3 — номер строки, где упало.
  3. Сама строка с ошибкой.
  4. Последняя строка — главное: тип ошибки и что случилось. Здесь: нельзя склеить строку с числом. Почини: str(age) или f-строка.

Модуль — готовый набор функций, который можно подключить словом import. Python поставляется с сотнями модулей.

  • import random — случайности: random.randint(1, 6) бросает кубик, random.choice(list) выбирает из списка.
  • import math — математика: math.sqrt(16), math.pi.
  • import datetime — даты и время.

Миллионы модулей, написанных другими людьми, ставятся командой pip install имя.
